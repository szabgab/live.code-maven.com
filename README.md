# Live Code-Maven events

The source of https://live.code-maven.com/

To check the data and generate the web site run the following:

```
uv run generate.py
```

To view the site locally run

```
rustatic --path site --indexfile index.html --nice
```


A new plan

Every event starts with with 30 min mingling in which people can introduce themselves. No recording.

Then the presentation where people can ask questions via chat that either the speaker can read or I can read for the speaker. This is recorded.

When we are done recording the presentation we have another open mic session. No recording.
